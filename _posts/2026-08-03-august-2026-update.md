### C++
- [How fast is C++26’s std::hive?](https://lemire.me/blog/2026/08/02/how-fast-is-c26s-stdhive/)<br>
  Prof. Daniel Lemire
  - [std::hive](https://en.cppreference.com/cpp/container/hive) is a new **sequential** container introduced in [C++26](https://en.cppreference.com/cpp/26).<br>
  - std::have automatically manages its storage in multiple memory blocks and it can reuse the memory locations of erased elements.<br>
  - Internally, std::hive is a linked list of blocks. Each block carries a skipfield: a small integer per slot that tells the iterator how many erased slots to jump over.<br>
  - From performance point of view, std::vector is still the most efficient data structure. std::hive performs better than std::list, but is not as efficient as std::vector.<br>

### Rust
- [How we saved 100 terabytes of memory by optimizing 1.1.1.1’s DNS cache](https://blog.cloudflare.com/dns-cache-memory-optimization-1111)<br>
  Sebastiaan Neuteboom, August 27, 2026<br>
  - Cloudflare's [Big Pineapple](https://blog.cloudflare.com/big-pineapple-intro/) platform stores over 250 billion DNS cache entries at any given time.<br>
  - At that scale, even 1 extra byte per entry costs more than 250 GB of memory!<br>
  - Big Pineapple is implemented in Rust.<br>
  - The post explains how analysis of the usage patterns, careful choice of the data structures e.g. Box<[T]> vs Vec<T> and through other application optimizations, they were able to reduce the aggregate working-set memory across the fleet by about 100 TB.<br>

### Storage
- [Infinite, shareable volume storage with Hunter Leath, Archil CEO](https://www.youtube.com/watch?v=0IIUKTygsyc)<br>
  The Database School Podcast, Jan 15, 2026
  - [Archil](https://archil.com)
    • aims to be the universal storage engine that sits on top of [Amazon S3](https://aws.amazon.com/s3/)<br>
    • allows you to have infinite storage in your own S3 bucket, but still be treated like a local disk with POSIX compatible filesystem<br>
    • introduces SSD cluster to speed things up<br>
    • clients interact with the SSD cluster and the cluster intelligently stores data to your S3 bucket<br>
  - Archil's solution addresses the common issues with handling lots of small files over network file system<br>
  - Archil also works with other cloud storage providers e.g. [Cloudflare R2](https://www.cloudflare.com/products/r2/)<br>

- [Object Storage Is All You Need](https://www.youtube.com/watch?v=ei0wwTy6_G4) - [Justin Cormack](https://www.linkedin.com/in/justincormack), Docker<br>
  Nov 16, 2024<br>
  - Typical object store performance characteristics<br>
    • high latency<br>
    • high parallelism<br>
    • dynamically scaled based on usage<br>
    • high sufficient throughput with sufficient parallelism<br>
  - Lots of proprietary and open source products are being built on top of object stores<br>
    • Analytical databases e.g. Snowflake, Databricks<br>
    • Virtual Disks e.g. [DIS: blockDevice over Immutable Storage](https://github.com/asch/dis)<br>
    • Embedded databases e.g. [SlateDB](https://github.com/slatedb/slatedb)<br>
    • Vector databases e.g. [turbopuffer](https://turbopuffer.com/)<br>
    • Kafka compatible data store e.g. [WarpStream](https://www.warpstream.com/)<br>
    • solution for mobile observability e.g. [bitdrift](https://bitdrift.io/)<br>
